Duplicate Detection Logic

Scenario Condition Action Reason
Active Record Exists IsActive = true SKIP Don't overwrite active data
Pending Record Exists PRM_Pending__c = true SKIP Already under review
Inactive Record Exists IsActive = false
PRM_IsErrorRecord__c = false		 UPDATE Reactivate existing
Error Record Exists PRM_IsErrorRecord__c = true CREATE NEW Preserve error history
No Record Exists — CREATE NEW Standard creation

Address Validation Flow

Precisely API Integration
  1. User enters address details in form
  2. LWC calls validateAddress() Apex method
  3. Apex invokes Integration Procedure PRMIPAddressValidation
  4. Integration Procedure calls Precisely API (external HTTP callout)
  5. Precisely returns standardized address + geocoding (lat/long) + confidence score
  6. Apex parses response and returns structured data
  7. LWC displays addressValidationModal with side-by-side comparison
  8. User selects "Recommended" (Precisely) or "Provided" (original) address
  9. Selected address is used in createNewLocation() with geocoding
Validation Confidence Badges:
🟢 Green: ≥90% confidence
🟡 Yellow: <70% confidence
🔴 Red: No match found
