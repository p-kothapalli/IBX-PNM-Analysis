**Legend**
- **AC**: AC1 = push-out; AC2 = independent-child-protection; REG = regression; FDP = FDP staging integrity; OS = OmniScript/IP; UI = LWC/UX; NEG = negative; BULK = bulk/governor.
- **Priority**: P0 = blocker, P1 = high, P2 = medium.
- **Type**: U = unit (no DML / mocks), I = integration (DML/full cascade), E2E = OmniScript or LWC end-to-end.
