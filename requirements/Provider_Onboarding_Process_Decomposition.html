Lane B — Ongoing (PDM)   provider enters the data-management ring after activation
Provider Change / PDM Manual Update

5 PDM guided flows (demographics, taxonomy, NPI, practice-location, billing/mailing address, networks, capitation) — each with a 5-step QC chain.

Re-Credentialing — every 2–3 yrs

4 scheduled batches (due-date, CAQH access, notification, letter). CAQH re-validation gate; re-enters at PSV with IsRecredentialing = true.

Off-Cycle Credentialing

Event-driven re-verification between cycles — abbreviated PSV + accelerated QC.

Termination / Reinstatement

Provider/PL leaves or returns. Reinstatement re-enters the journey at Application Review.

External integration touchpoints

CAQH · profile + attestation pre-fill, recred gate NPDB · adverse-action verification (in PSV) Precisely · address standardization NPPES / FSMB · license & NPI verification BCBSA · inter-Blue practitioner / role sync NCPDP · pharmacy provider data RCAT · roster compliance feed UPHS / UPenn · roster reconciliation (batch)
Handoff chain: Provider → Outreach → Case routed (round-robin) → PSV Analyst → Final Submit → Network Case Manager (PDA) → QC Reviewer → routine → Activation  or  non-routine → Medical Director → HACAC Committee → Activation → PDM Ops.  Returns to a prior stage restore the original owner (no fresh round-robin).
