Guided Flow Hands-On Exercises
45 OmniScript flows grouped into 12 exercise sets. Each set includes 2–3 use-case scenarios per flow so developers learn edge cases, not just happy paths. All exercises must be completed in a sandbox environment.
💡
Exercise Rule: Every flow should be run a minimum of 2–3 times with different scenarios. This surfaces error handling, validation logic, and downstream record creation patterns that a single run will not expose.

🎯 Capstone Exercise (Day 60) — End-to-End Provider Lifecycle Trace

Developers must be able to answer all five questions below without assistance to be considered onboarding-complete:

  1. A new practitioner submits a PAR form — which OmniScript launches? Which IPs are called? Which DataRaptors create records? Which Apex classes fire?
