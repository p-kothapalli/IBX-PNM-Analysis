How Configuration Works

  • Dashboard Component: Reads flowType and loads corresponding tile configuration from custom metadata
  • Tile Rendering: Iterates through tiles array and renders each tile with status (Pending/In Progress/Completed)
  • Modal Loading: When tile clicked, dynamically loads component specified in configuration
  • Mode Parameter: Components check mode parameter to adjust behavior (e.g., "initial" vs "delta" for ReCred)

Add New Flow in Minutes

To support a new flow (e.g., "Initial Cred QC"), simply create a new configuration record - no code changes needed. The dashboard will automatically render the tiles based on the configuration.

Key Benefits

Business Benefits

  • Eliminates 4MB Payload Failures: Each tile saves independently (max ~100KB per tile)
  • Flexible Workflow: Review tiles in any order based on data availability
  • Resume Capability: Exit at any point and resume later without losing work
  • Visual Progress Tracking: Green checkmarks show completed tiles at a glance
  • Collaboration: Multiple reviewers can work on different tiles simultaneously

Technical Benefits

  • Configuration-Driven: Add new flows by creating configuration records, no code changes
  • 60% Code Reuse: Shared framework and components across 3 flows
  • Modular Architecture: Each tile is an independent LWC component
  • Performance: Lazy loading - only load data for active tile
  • Scalability: No payload limits, handles any data volume
  • Maintainability: Component-based design, easier to debug and enhance
