How We Estimated

Grounded, not guessed — audit → TDD → estimate, one feature at a time

🔎 A repeatable method for every priority

1.
Audit the real codebase, OmniStudio assets, and requirement docs — what exists today vs. what's net-new.
2.
Write a high-level TDD — objects, services, flows, integration points, and the risky edges.
3.
Confirm scope with the business through targeted clarifying questions before sizing.
4.
Size in developer-days — a baseline number and an AI-assisted number, with a t-shirt size and a confidence rating.

📈 Why this is higher than the first pass

The FY2025-anchored first pass summed to ~600–1,100 story points. The grounded re-estimate is ~1.6–2.7× higher on the big-ticket items — driven by work the anchors quietly omitted: all-5-flow tile redesign, real CAQH document retrieval, the versioning state-machine across ~30 objects, the async engine build, and the LexisNexis termination cascade.

⚙️ AI-assisted multipliers (repo-calibrated)

The AI-assisted number applies realistic acceleration by work type — heavy on code & tests, near-zero on UAT, integration, and OmniStudio publishing.

Read Before Summing

Shared foundations — don't pay for the same thing twice

Several priorities depend on the same building blocks. We book each foundation once with its primary owner, and the consumers reuse it. Sequencing foundation-first turns overlap into savings.

Shared foundation Primary owner Also consumed by
Async / bulk engine (PRM_AsyncJob__c)F7F1 (PEAR QC intake), F5
External-submission QC routing (Case / CM / CDM + CMA)F1 / F7F3, F5, F8
Versioned / effective-dated write modelF4F5 (no re-entry), F6 (history feeds), F8 (termination)
Analyst worklists / routingF3F5 (shared views), F6 (leadership inventory)
Field-history data sourceF4F6 (integrity feeds)
Tile + session UI frameworkF2F7 mass-update grid cells
🧱

Build foundations first

F7 async engine and F4 versioning are the two spines. Nearly everything else attaches to them.

🔗

Net-new is already deducted

F5 is booked net-of-overlap; F9 excludes items owned by F3/F4/F7. The totals won't double-count.

💸

Sequencing saves real effort

F7→F1, F4→(F5/F6/F8), F3→(F5/F6) reuse work already paid for elsewhere.
